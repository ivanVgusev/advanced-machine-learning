# Отчет по лабораторной работе №1

## Цель работы

Построить мультимодальную модель для классификации музыкальных треков по жанрам на основе аудио и текста песен.

## Данные

Использован датасет PMEmo2019. В работу включены треки, для которых доступны аудиофрагмент, текст песни и жанровая разметка.

- Количество примеров: `$samples_count`
- Жанры: `$genres`

## Подготовка признаков

- Аудио: первые 30 секунд трека, частота дискретизации 16 кГц, эмбеддинги Wav2Vec2.
- Текст: текст песни без временных меток, эмбеддинги BERT.
- Эмбеддинги каждой модальности усредняются до одного вектора на трек.

## Модель

Использован подход intermediate fusion. Аудио- и текстовые признаки проецируются в пространство размерности 256, объединяются трансформером и передаются в классификатор жанров.

## Обучение

- Количество эпох: 150
- Оптимизатор: `$optimizer`
- Скорость обучения: `$lr`
- Функция потерь: `$loss_function`
- Устройство: `$device`
