# Лабораторная работа №1

# Multimodal Music Emotion Recognition using Audio--Lyrics Fusion Transformer

## Промежуточное фузирование аудио- и текстовых представлений с помощью Transformer

------------------------------------------------------------------------

## 1. Цель работы

Цель лабораторной работы:

Реализовать модель промежуточного фузирования (intermediate fusion) для
мультимодальных данных, состоящих из:

- аудиосигнала музыкального произведения;
- текста песни (lyrics).

Модель должна получать совместное мультимодальное представление (joint
representation), объединяющее информацию из обеих модальностей, и
использовать его для определения эмоционального содержания музыкального
произведения.

------------------------------------------------------------------------

## 2. Постановка задачи

Музыкальное произведение содержит информацию о настроении в нескольких
источниках.

### Аудиомодальность

Аудиосигнал содержит:

- темп;
- ритм;
- гармонию;
- инструментальный состав;
- динамику;
- особенности исполнения.

### Текстовая модальность

Текст песни содержит:

- семантику;
- эмоциональные слова;
- тему песни;
- контекст.

Отдельные модальности могут противоречить друг другу:

- весёлая музыка + грустный текст;
- агрессивная музыка + позитивный текст.

Поэтому необходимо не просто объединить признаки, а построить общее
мультимодальное пространство.

------------------------------------------------------------------------

# 3. Используемый подход

Используется intermediate fusion:

    Audio
     |
    Audio Encoder
     |
    Audio representation

            ↓

    Fusion Transformer

            ↑

    Text representation
     |
    Text Encoder
     |
    Lyrics

Каждая модальность сначала обрабатывается отдельным encoder-ом. Затем
Transformer строит совместное представление.

# 6. Архитектура модели

## Audio Encoder

Используется wav2vec2:

<https://huggingface.co/facebook/wav2vec2-base>

Вход:

    audio waveform

Выход:

    audio embeddings
    (sequence_length, hidden_size)

------------------------------------------------------------------------

## Text Encoder

Используется BERT:

<https://huggingface.co/google-bert/bert-base-uncased>

Вход:

    lyrics text

Выход:

    text embeddings
    (sequence_length, hidden_size)

------------------------------------------------------------------------

## Fusion Transformer

Полученные последовательности признаков объединяются:

    [
    audio tokens,
    text tokens
    ]

Transformer обучается находить зависимости:

    audio pattern ↔ word meaning

После этого получается:

    joint multimodal representation
