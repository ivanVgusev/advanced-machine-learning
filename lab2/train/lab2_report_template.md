# Отчет по лабораторной работе №2

## Цель работы

Построить multi-task модель, которая по аудиозаписи одновременно определяет говорящего персонажа и сентимент реплики.

## Данные

Использован набор аудиозаписей MELD из сериала «Друзья». В выборку включены реплики шести главных персонажей, для которых найден аудиофайл.

- Количество примеров: `$samples_count`
- Обучающая выборка: `$train_count`
- Тестовая выборка: `$test_count`
- Персонажи: `$speakers`
- Категории сентимента: `$sentiments`

## Подготовка признаков

Аудио приведено к частоте дискретизации 16 кГц и разбито на окна по 0,5 секунды. Для каждого окна извлечены MFCC, chroma, spectral centroid, spectral bandwidth, spectral rolloff, zero crossing rate и RMS. Признаки усреднены по окнам и стандартизированы.

- Размер вектора признаков: `$embedding_size`

## Модель

Общий полносвязный энкодер переводит входные признаки в пространство размерности 256. После него используются две отдельные головы: для классификации персонажа и для классификации сентимента.

## Обучение

- Количество эпох: `$epochs`
- Оптимизатор: `$optimizer`
- Скорость обучения: `$lr`
- Функция потерь: `$loss_function`
- Итоговая сумма потерь: `$final_loss`
- Устройство: `$device`
- Сохраненная модель: `$model_path`
